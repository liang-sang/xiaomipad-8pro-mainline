# Stock piano sensor configuration

Static ODM/vendor configuration from OS3.0.303.0.WPYCNXM. Each source path and
SHA256 is in `source.json`. This is not the persist registry. ROM default
`fac_cal` entries are generic; unit-specific persist calibration is excluded.

Distribution follows [firmware/README.md](../README.md#distribution-policy).
Payload files are identified by [REUSE.toml](../../REUSE.toml); this README and
`source.json` are project metadata, licensed under MIT. For private calibration staging, see
[the sensor guide](../../device/sensors/README.zh-CN.md).
